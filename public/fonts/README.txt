Self-hosted brand fonts for discover-milwaukee.com
===================================================

These are the Latin and Latin Extended subsets published by Google Fonts,
served from this site so pages do not need a second connection to load them.

Anton   v27  Copyright 2020 The Anton Project Authors (https://github.com/googlefonts/AntonFont.git)
Jost    v20  Copyright 2020 The Jost Project Authors (https://github.com/indestructible-type/Jost)
             Variable font, weight axis 100-900. The site uses 400-700.
Damion  v15  Copyright 2014 The Damion Project Authors (https://github.com/googlefonts/damionFont)

All three are licensed under the SIL Open Font License, Version 1.1.
License text: https://openfontlicense.org/open-font-license-official-text/

The @font-face rules and the size-matched fallback faces are in styles/globals.css.
If a font is updated, re-measure the fallback values there.
